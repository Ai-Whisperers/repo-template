# API Reference

## Client

### `Client(api_key=None, **kwargs)`

Create a new client instance.

**Parameters:**
- `api_key` (str, optional): API key for authentication
- `timeout` (int, optional): Request timeout in seconds

**Example:**
```python
client = Client(api_key="...")
```
